OpenClaw Platform

La base de una plataforma de automatización para muchos negocios a la vez. Cada cliente ve solo sus datos, y ese aislamiento lo garantiza la base de datos, no solo el código.

  • Panel en Next.js y React con control de acceso por rol: super admin, admin y staff de cada tenant.

Migración de 10 años de datos

Una década de información en SQL Server tenía que pasar a MongoDB sin perder relaciones ni detener la operación. Diseñé y construí el pipeline completo.

  • ETL en Python: unas 25 tablas relacionadas por lote, de 100 a 200 registros cada uno.
  • De 5 lotes cada 10 minutos a 50 lotes cada 5 minutos: 20 veces más rápido.
  • Re-migración selectiva: corregir un lote pasó de 10 minutos a menos de 1.
  • Monitoreo que levanta contenedores Docker para reprocesar y avisa por correo si el error persiste.
